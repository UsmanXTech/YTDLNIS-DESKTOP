# YTDLnis Desktop

Native Windows desktop implementation of the YTDLnis concept using C++20, Win32, Direct2D, DirectWrite, CMake and MSVC.

## Status
Phase 1 — repository audit and native architecture.

This repository intentionally contains no Kotlin/JVM/Compose Desktop/Java/.NET/Python/Node/Electron/Qt/GTK/Flutter UI runtime.

See `docs/ARCHITECTURE.md` for the audited architecture and implementation plan.
